# WrapPin 隐私说明

[English](Privacy.md)

WrapPin 将敏感的定位与配对信息保留在 iPhone 上。

## 保留在 iPhone 上的信息

除下文所述的主动外部搜索与列车数据请求外，WrapPin 不会发送：

- 坐标、选择的地点或地址。
- 搜索内容、收藏或定位历史。
- 步行路线、路线进度或速度。
- 配对记录、配对 PIN 或加密材料。
- Apple ID、设备名称或个人信息。
- 连接诊断或支持报告。

配对记录保存在仅限本机使用的钥匙串中。偏好设置和保存的地点保留在 App 本地存储中。

“模拟收藏地点”快捷指令会把收藏的名称和地点描述提供给本机的“快捷指令”App 和 Siri，以便选择收藏地点；不会向它们提供坐标。快捷指令不会新增任何网络请求或统计事件。

海外地点搜索是可选功能，只在配置了 Geoapify API Key 的版本中出现。只有把搜索框切换为“海外”并轻点“搜索”时，搜索内容才会通过 HTTPS 发送给 [Geoapify](https://www.geoapify.com/privacy-policy/) 以查找候选地点；输入过程中、国内模式下或粘贴坐标时都不会发送。Geoapify 可以看到请求 IP 地址等连接信息。请求不包含坐标、配对数据、设备名称或诊断信息。近期结果在 iPhone 上缓存 7 天，每日搜索次数也只保存在本机，两者都不会上传，也不会进入使用统计。

App 打开时会向 GitHub 请求最新公开版本的信息，以检查更新。请求不包含定位、配对或诊断数据。与其他网络请求一样，GitHub 可以看到请求 IP 地址等连接信息。

## 实验性 SBB 版本

独立的 **WrapPin SBB** target 通过 HTTPS 向官方 `api.opentransportdata.swiss` OJP 服务发送车站搜索文本、选定车站标识、出发时间及具体列车服务标识。请求仅在主动搜索时和实时回放期间每分钟发送一次。服务商会收到个人 API 令牌以及 IP 地址等连接信息。本功能不向其发送设备真实或模拟坐标、配对记录、Apple 凭据或诊断信息。

OJP 令牌及列车响应仅保留在当前 App 会话内存中，不写入 UserDefaults、日志、恢复记录或安装包。现有定位会话仍在本机保存最后位置恢复记录，以便中断后恢复真实位置；不会自动继续列车回放。该 target 未配置统计目标，并禁用了上游版本检查。现有标准版和隧道版不显示或激活实验性列车界面。

## 可选的后台定位指示器设置

“设置 → 后台定位指示器 → 减少后台定位指示器”是可选功能，默认关闭。默认的会话流程仍只申请“使用 App 期间”权限，并显示蓝色后台定位指示器。

只有用户主动打开开关时，才会申请升级为“始终”定位权限。尚未授权时，先申请“使用 App 期间”，获得后再申请升级。读取已保存的开关、打开 App、启动会话或回到前台，都不会申请升级。如果系统不再弹出升级提示、你拒绝过升级，或选择了“允许一次”，可通过页面上的入口打开系统设置，改为“始终”。开关选择与 iOS 实际授予的权限分别显示。

仅在开关开启且已有“始终”权限时，WrapPin 才请求隐藏指示器；其他情况均请求显示，最终显示由 iOS 决定。iOS 27 灵动岛表现以及锁屏、长时间后台保持的效果仍需真机验证。iOS 可能会定期提醒 WrapPin 在后台使用位置。关闭开关恢复显示指示器，但 App 无法撤回“始终”权限；需要时请在系统设置中改回“使用 App 期间”。结束模拟后仍会停止后台定位更新。

开关保存在本机 UserDefaults 中。后台保持收到的坐标不会保存或上传；用户选择的模拟地点与恢复记录仍按原有方式保存在本机。本功能不新增统计事件或位置数据收集，也不改变下方的可选匿名统计。隐私清单保持不变：未收集位置数据，已有的 UserDefaults 声明也涵盖这项本地偏好。

## 可选的匿名使用统计

App 提供“分享匿名使用统计”，默认关闭。新用户会在完成设置前看到开关，只有主动开启后才发送统计。升级时保留现有安装已保存的选择，可随时在“设置 → 隐私”中修改。

开启分享后，App 可能统计：

- 参与统计的安装打开 App 或回到前台。
- 完成引导或配对。
- 成功启动固定位置、步行或驾车会话。
- 在运行中的会话里更新位置。
- 事件对应的 App 版本与 build。
- TelemetryDeck 添加的大致事件时间。

这些只是使用活动信号，不含操作涉及的位置、路线或其他用户内容。

## 安装计数

App 在本地存储中为本次安装生成随机标识，并发送不可逆的 SHA-256 哈希，用于估算参与统计的安装数，不使用姓名、Apple ID、广告标识或硬件标识。每次启动不会额外发送会话标识。

关闭分享会立即阻止后续事件，并删除本地标识。再次开启时会生成新标识，因此 WrapPin 无法关联退出前后的活动。关闭分享无法撤回 TelemetryDeck 已收到的匿名事件；这些事件不含位置或个人身份。

统计反映的是参与分享的安装，并非所有下载或使用者。

## 服务与数据最小化

WrapPin 通过 HTTPS 直接向 TelemetryDeck Ingest API 发送固定事件列表，不嵌入第三方统计 SDK，避免 SDK 自动添加设备信息。TelemetryDeck 表示不会保存 IP 地址，冷存储中的事件大约保留 7–10 年，且不保证准确的删除日期。详见 [TelemetryDeck 隐私说明](https://telemetrydeck.com/docs/guides/privacy-faq/)。

如果版本中未配置 TelemetryDeck App ID 和 namespace，统计客户端不会发送任何信息。

## 后续变更

未来收集信息如有变化，必须在发布前同步更新本文与 App 内的“分享哪些信息”页面。
