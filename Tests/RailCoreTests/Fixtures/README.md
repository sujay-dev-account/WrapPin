`official-lir-response.xml` is the full published OJP 2.0 response example from
https://opentransportdata.swiss/de/cookbook/open-journey-planner-ojp-landing-page/ojplocationinformationrequest-2-0/
retrieved 29 October 2026, extracting the XML text from its HTML syntax highlighting.
It is an official documentation example, not a live query recorded by this build.
The source requires attribution to opentransportdata.swiss.

Small train fixtures are authored in OJPClientTests.swift to test specific parser
and safety conditions. No production coordinates, tokens or pairing data are included.
